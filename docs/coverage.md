# Coverage tiers

| Tier | Pads | What is evaluated |
| --- | --- | --- |
| A | Cape Canaveral SFS, Kennedy Space Center, Vandenberg SFB | Launch commit criteria proxies for every vehicle, plus the liftoff wind limit for Falcon 9 and Falcon Heavy; other vehicles show liftoff wind as "no published limit". Official comparison for the two Florida sites |
| B | SpaceX Starbase, Wallops | The same proxies as reference only: no public evidence says these ranges apply the criteria |
| C | Every other pad | ECMWF members only, to stay within the request budget, and no rule headline |
