### Thick Cloud Layers Rule (`thick_cloud`)

Section 4.1.8, LLCC rules 22, 23, 24. Confidence: medium.

> Do not launch through a non-transparent cloud layer at least 1.4 km thick with any part between 0 and -20 °C within 5 nmi slant distance of the flight path.

Proxy `thick_cloud` reads: `cloud_cover_levels`, `temperature_levels`, `geopotential_height_levels`.

| Parameter | Value | Set by |
| --- | --- | --- |
| `cloud_cover_min_pct` | 50 | Scrubcast |
| `thickness_min_m` | 1400 | Published rule |
| `thickness_comparator` | >= | Published rule |
| `t_min_c` | -20 | Published rule |
| `t_max_c` | 0 | Published rule |

Plotted variable: `qualifying_layer_thickness`, threshold `>=` 1400 m. Readout: "N of M members have a cloud layer 1,400 m or thicker between 0 and -20 °C".

Approximation: Cloud cover is estimated from relative humidity on ten pressure levels at one grid point. Layer thickness is quantised to level spacing. The cirriform and radar exemptions cannot be evaluated, so this proxy over-reads.
